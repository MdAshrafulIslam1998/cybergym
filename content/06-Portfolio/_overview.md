# Module 06 — Portfolio

This module is what an employer or migration assessor sees first. The goal is **proof of skill**, not noise. Each entry has:

- a problem framing
- evidence I did the work (screenshots, code, repo links)
- a reflection on what I learned

## Structure

### Lab writeups
Box-by-box. Filed under `06-Portfolio/labs/`. Use [[../99-Templates/lab-writeup-template|the lab template]].

### Original projects
Larger, multi-week. Each gets its own subfolder with a README, code, results, and writeup.

### Blog-style posts
Short, opinion-tinged write-ups. Suitable for Hacker News, /r/netsec, LinkedIn. Examples to write later:
- "I'm a data scientist learning security from scratch — here's the curriculum I built"
- "OWASP LLM-01 (prompt injection) explained, with reproducible attacks"
- "What CompTIA Security+ doesn't teach you about real SOC work" *(after I have SOC experience)*

### Public site
Once Quartz is configured, this folder is what gets featured on the trupples site landing page.

## Quality bar

- I prefer **5 tightly-written posts** to 50 thin ones.
- Every claim sourced. Every screenshot annotated.
- Code in any project repo must run from a fresh clone with one README.
