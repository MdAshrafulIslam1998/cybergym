# Module 03 — Cybersecurity Core

The shared vocabulary of security work — the stuff that's on every entry-level exam and in every job description.

## Sections (to be filled in)

- **Foundational concepts** — CIA triad, AAA (auth, author, accounting), risk vs threat vs vulnerability, defense-in-depth, zero-trust.
- **Cryptography** — symmetric vs asymmetric, hashing, PKI, TLS, common pitfalls.
- **Threats and attacks** — malware taxonomy, phishing, social engineering, MITRE ATT&CK framework, common CVE classes (XSS, SQLi, SSRF, RCE, etc.).
- **Defenses** — IAM, MFA, network segmentation, SIEM, IDS/IPS, EDR/XDR, endpoint hardening, patch management.
- **Operations** — incident response lifecycle, threat hunting, forensics basics, compliance frameworks (ISO 27001, NIST CSF, Essential Eight for AU).
- **Governance / Risk / Compliance (GRC)** — light touch, just enough to discuss intelligently in interviews. I'm not building a GRC career.

## Cert mapping
This module's content is roughly the union of CompTIA Security+ + ISC2 CC + parts of CySA+. As I prep those certs, the exam objectives become the section headings here.
