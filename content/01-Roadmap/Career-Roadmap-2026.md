# Career Roadmap — 2026 to 2028

> The original deep-research note that produced this plan is preserved at [[../career_roadmap|career_roadmap.md]] (root of the repo). This file is the **working version** I update as I progress.

## North Star

By **end of 2027** I want to be holding:

- ☐ ISC2 CC + CompTIA Security+ + one Linux cert + Microsoft SC-200
- ☐ A public Quartz site (this vault) with at least 60 substantive notes and 10 lab writeups
- ☐ One unpaid security/ML-security internship completed in Sydney (or remote-AU)
- ☐ One original AI-security project on GitHub with a writeup
- ☐ ACS skills-assessment-ready evidence file

By **end of 2028** I want to be holding:

- ☐ A paid security-coded role in Sydney (482 sponsorship or 485 work-rights)
- ☐ Either AZ-500 or AWS Security Specialty
- ☐ A second AI-security project, ideally with a small academic publication or workshop submission
- ☐ Visa application in flight for 189/190 PR

This is the success condition. Every milestone below feeds it.

## Milestones (gates, not deadlines)

The vault's lifelong-course philosophy says: no week-by-week timeline. Instead, **gates** — things that must be true before the next phase makes sense.

### Gate 1 — "I own the basics" (target: ~3–5 months in)

- [ ] Can explain TCP/IP handshake, DNS resolution chain, HTTP request lifecycle, OSI layers in my own words without notes
- [ ] Comfortable on Linux command line: file/permission/process/networking commands without Googling
- [ ] Read & wrote shell scripts; comfortable with bash, jq, grep, awk, sed
- [ ] Completed [TryHackMe Pre-Security path](https://tryhackme.com/path/outline/presecurity)
- [ ] Vault module 02-Foundations is filled in (15+ notes)
- [ ] **ISC2 CC passed** (free voucher)

→ Unlocks: serious Tier 1/2 cert prep.

### Gate 2 — "Industry-baseline credibility" (target: ~9–12 months in)

- [ ] **CompTIA Security+ passed**
- [ ] Completed TryHackMe SOC Analyst Level 1 path
- [ ] 5 lab writeups on the public site (HTB easy machines or THM rooms)
- [ ] Comfortable in a SIEM (Splunk free / Sentinel free tier / Elastic) — wrote at least 10 detection rules
- [ ] Vault has 30+ notes, modules 02 + 03 substantively populated

→ Unlocks: applying for unpaid SOC analyst internships, junior CTF teams, security communities (BSides Sydney, AISA).

### Gate 3 — "Specialist signal" (target: ~12–18 months in)

- [ ] **CySA+ OR PNPT passed**
- [ ] **Microsoft SC-200 passed**
- [ ] First AI-security project public on GitHub + writeup
- [ ] At least one unpaid internship completed and reference letter secured
- [ ] Vault has 60+ notes; site is being read (Plausible/GoatCounter analytics)

→ Unlocks: applying for paid sponsored security roles in 2028; Master-by-Research applications with a clear research direction.

### Gate 4 — "Specialization + employability" (target: ~18–24 months in)

- [ ] **AZ-500 OR AWS Security Specialty passed**
- [ ] Second AI-security project (deeper) with a workshop-style writeup
- [ ] OWASP LLM Top 10 series published on the site (10 posts)
- [ ] Active in a Sydney security community (talk given, lab-night attended, write-up shared)
- [ ] Paid security role secured (or sponsored offer in hand)
- [ ] PR points-test target met

## Daily/weekly rhythm (non-prescriptive)

Whenever I touch this work I aim for at least one of:

1. Add or expand a note in the vault
2. Complete a lab/room and start its writeup
3. Read part of a cert objective and link concepts back to existing notes
4. Read one security-research paper or blog post and add it to a "papers I read" log

Skipping a day is fine. Skipping the act of writing things down is the failure mode to avoid.

## Communities to plug into (Sydney)

- AISA (Australian Information Security Association) — has a Sydney chapter and student tier
- BSides Sydney — annual community conference, CFP usually open ~6 months ahead
- OWASP Sydney chapter
- SecTalks Sydney (monthly meetup)
- Sydney Linux User Group (SLUG)
- University security clubs — UNSW SecSoc, USYD CSESoc security stream

These build the network I need to find unpaid internships informally — most don't get advertised.
