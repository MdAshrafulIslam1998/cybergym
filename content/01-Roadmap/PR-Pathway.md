## ACS skills assessment

Required for any 189 / 190 / 491 visa using an ICT ANZSCO code. ACS assesses:

- The relevance of my qualification (Master of Data Science → likely classed as a Bachelor-or-higher ICT qualification with major in computing — confirm during pre-assessment).
- Years of relevant work experience after the qualification was completed.

### Practical implications
- Internships count toward experience **only if** they are paid, with a TFN, and clearly within the assessed occupation. Unpaid internships may not count for ACS — verify before accepting one purely for migration value.
- Job titles on contracts must align with the assessed ANZSCO code.
- Keep clean evidence: signed contracts, payslips, reference letters explicitly listing the security duties.

## Visa pathway options

### Option A — Subclass 485 (Temporary Graduate) → 189/190/491

**Step 1.** Finish Master of Data Science → apply for subclass 485 (post-study work visa).

**Step 2.** Use 485 work-rights window to:
- Land a paid security-coded role (or convert TFN job toward security duties if possible).
- Finish ACS-relevant cert stack (Security+, SC-200, AZ-500 etc).
- Optionally do Master by Research at a **regional** campus to extend post-study work + access regional PR concessions.

**Step 3.** Apply for 189 (skilled independent), 190 (state-sponsored), or 491 (regional skilled).
- **190** typically requires NSW state sponsorship — check NSW skilled occupation priorities for the year.
- **491** requires regional living/work — Sydney does **not** count as regional for visa purposes. Newcastle, Wollongong, Hobart, Adelaide, Darwin, etc., do.

### Option B — Sponsored work visa (subclass 482) before PR

If a Sydney employer offers a 482 sponsorship for a security role, that path can run in parallel and accumulate 2 years of skilled work toward 186 ENS or transition-stream PR. Sponsorship is realistic for senior roles, harder for junior — which is why the unpaid-internship-now / paid-security-role-by-2028 path is the main play.

## The Sydney problem

Sydney is metro-coded for migration purposes — no regional concessions. To compensate I need to:

- Score higher on the points test (age, English, qualifications, partner skills, NAATI bonus, professional year, regional study).
- Or take Master-by-Research at a regional campus before applying.
- Or accept that 189 is competitive and aim for 190 NSW (state-nominated) which lowers point threshold but adds state criteria.
