# Module 07 — Certifications

This module is per-cert exam prep. Each certification gets its own folder. Inside each folder:

- `_overview.md` — created from [[../99-Templates/cert-prep-template|the cert-prep template]], lists exam objectives and links them to vault notes.
- One sub-note per exam domain.
- A `mistakes-log.md` — every wrong practice question, in my own words.
- A post-mortem after the exam attempt.

## Stack and order

See [[../01-Roadmap/Certification-Stack|the certification stack]] for the full reasoning. Folders to create as I begin each cert:

- `ISC2-CC/` — first cert (free voucher)
- `Network-Plus/` — networking foundations
- `Linux/` — LPI Linux Essentials or Linux+
- `Security-Plus/` — industry baseline
- `CySA-Plus/` — blue-team analyst
- `SC-200/` — Microsoft Security Operations Analyst
- `AZ-500/` — Azure security (or `AWS-Security-Specialty/`)

I will only create a folder when I genuinely begin prep. No empty placeholders.

## Why notes per cert (not just one big notes pile)

- Exam-specific vocabulary varies (CompTIA's "MOA" of risk vs ISC2's wording).
- A cert folder makes a clean handoff to "I'm sitting the exam this week" mode.
- Post-exam, the cert folder becomes a public artifact: "here's what I actually studied."
